## 自家製麺キリンジとは

2006年12月創業、宮城県仙台市青葉区二日町のラーメン店です。

「あぶらかすのカスラーメン」を中心に、自家製麺を活かした一杯を作り続けています。

## 🍜 お店・メニューについて
* **看板メニュー**：あぶらかすのカスラーメンのコッテリとアッサリ
* **メニュー表**：[メニューを見る](https://jikaseimen.github.io/jikaseimenkirinji/3d.html)
* **創業**：2006年12月
* **こだわり**：自家製麺と旨味が凝縮されたあぶらかすの相性抜群な一杯をご提供しています。
* 2009年11月からは「あぶらかす」のテイクアウトも実施しています。
